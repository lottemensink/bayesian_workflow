# Bayesian Workflow
This repository contains the online appendix to the manuscript "Developing and Evaluating Bayesian Models in Audit Research: A Practical Workflow". 

# Repository contents
| File | Description |
|---|---|
| `R Code: Bayesian Workflow for Audit Researchers.Rmd` | R code for the application of the Bayesian workflow to audit fee data, including a brief explanation of the steps that are taken. |
| `EdgarUSD.csv` | Audit fee data obtained from the SEC EDGAR database, used in `R Code: Bayesian Workflow for Audit Researchers.Rmd`. |
| `SBC.Rmd` | R code for the simulation-based calibration of the different model specifications. |
| `sbc_results1.RData` | Saved results from the simulation-based calibration of Model 1 in `SBC.Rmd`, used in `R Code: Bayesian Workflow for Audit Researchers.Rmd`. |
| `sbc_results2.RData` | Saved results from the simulation-based calibration of Model 2 in `SBC.Rmd`, used in `R Code: Bayesian Workflow for Audit Researchers.Rmd`. |
| `sbc_results3.RData` | Saved results from the simulation-based calibration of Model 3 in `SBC.Rmd`, used in `R Code: Bayesian Workflow for Audit Researchers.Rmd`. |

# Data availability

The audit fee data are provided in this repository. The firm complexity data are not included but can be obtained from the [XBRL Research website](https://www.xbrlresearch.com/#firm-complexity) by downloading *“Firm Complexity (ARC) Data”* in Excel format.
